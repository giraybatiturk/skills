# Geliştirme

Kod işi için akış. Sıra: `/yeni-ozellik` (kod öncesi) - kod - `/modul-kontrol` (eksik senaryo) - `/tasarim-kontrol` (ekran) - `/perf-kontrol` (bundle) - yayın.

- **giray**: router. Ne istediğini söyle, doğru skill'i seçer.
- **yeni-ozellik**: niyet keşfi, mevcut durum ölçümü, sekiz sınıfta senaryo, beş başlık, onay kapısı.
- **modul-kontrol**: yazılmış modülde yetki, durum geçişi, hata yolu, boş hal, çok kullanıcı, üçüncü parti, sözleşme, dağıtım sınıflarında eksik avı.
- **perf-kontrol**: ilk yükleme ve lazy chunk bütçesi; aşımın kaynağı; reçete; öncesi/sonrası ölçüm.
