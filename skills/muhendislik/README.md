# Mühendislik

the upstream workflow (MIT) ana akışının kopyası; her SKILL.md'nin tepesinde "Giray uyarlaması" bloğu var. Upstream'i güncellemek için ilgili klasörü yeniden kopyala, bloğu koru.

Sıra: `/setup` (bir kez) - `/grill-with-docs` - `/to-spec` - `/to-tickets` - `/implement` (içinde `/tdd` + `/code-review`). Yan girişler: `/triage`, `/diagnosing-bugs`, `/prototype`, `/research`.

Alınan: setup, grilling, grill-me, grill-with-docs, to-spec, to-tickets, implement, tdd, code-review, diagnosing-bugs, triage, prototype, research. Alınmayan: wayfinder, domain-modeling, codebase-design, wizard, improve-codebase-architecture, in-progress ve misc; ihtiyaç olursa eklenir.
